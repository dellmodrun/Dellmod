# Benthic

**Proof-of-Useful-Compute mining for AI, settled on Robinhood Chain.**

Benthic rewards miners in **$BENTHIC** for contributing verifiable AI computation
(inference and training jobs) — not wasted hashpower. Work is metered in verified
TFLOP-hours, checked by a redundant verifier mesh, pooled in an open mining pool
(the *Trench*), and settled on Robinhood Chain.
